# TPI-Torneo-Argentino-de-Futbol
Introducción:

El sistema a desarrollar permitirá gestionar una temporada anual de la Liga de Fútbol Profesional Argentino. Para ello contará con un menú principal destinado a la carga y administración de los partidos disputados durante el campeonato, además de submenús para la gestión de clubes, jugadores y contratos.
El objetivo del programa es registrar los resultados de los partidos y actualizar automáticamente la tabla de posiciones a medida que se desarrollan las distintas fechas del torneo anual. A partir de esta información, el sistema determinará la clasificación final de los equipos y establecerá cuáles obtienen las plazas para las competiciones internacionales, como la Copa Libertadores y la Copa Sudamericana, de acuerdo con el reglamento vigente.
Asimismo, el sistema contempla la etapa de eliminación directa que se disputa al finalizar la fase regular del campeonato. En esta instancia, los equipos mejor ubicados en la tabla anual se enfrentarán en cruces de eliminación directa hasta definir al campeón de la temporada. Además, se podrán generar informes sobre posiciones, clasificaciones a copas internacionales, campeones y descensos.
